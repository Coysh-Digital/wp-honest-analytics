# About this repository

This is the free edition of Honest Analytics, published exactly as it installs.

**It is generated, not developed here.** The source lives in a private
repository, and this one is rebuilt from it on every release by a script, so an
edit made here would be overwritten by the next one. That arrangement is
deliberate: it is what guarantees the free and paid editions never drift apart.

## Reporting something

Issues and questions are welcome here - please open an issue. Bugs, unclear
wording, a report that shows the wrong number, a host it does not work on: all
useful, all read.

## Pull requests

They cannot be merged here directly, for the reason above. That does not make
them unwelcome: a pull request is a perfectly good way to show exactly what you
mean, and the change will be applied upstream with credit.

## Security

Please do not open a public issue for a security problem. Email
security@coysh.digital instead.
